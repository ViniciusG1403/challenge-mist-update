# Challenge Mist — atualizações

[Baixar a versão mais recente para Windows](https://github.com/ViniciusG1403/challenge-mist-update/releases/latest)

Baixe o instalador `ChallengeMist-VERSAO-Setup.exe` na página da versão e instale na mesma pasta do jogo. Seu progresso e suas jornadas são preservados.

A partir da versão 0.15.2, o atalho abre uma tela que verifica, baixa e instala as atualizações antes de entrar no jogo. Se não conseguir conectar, você pode tentar novamente ou jogar a versão instalada.

Quem ainda usa uma versão configurada com o endereço antigo precisa instalar a nova versão uma vez. Depois, as próximas atualizações usam este repositório automaticamente.

Cada release inclui o instalador e o manifesto assinado `challenge-mist-update.json`. As novidades de cada versão estão na descrição da release.
